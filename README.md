# 🍎 Шоп-Калькулятор Выгоды (Shop Calculator PRO)

> **Умный веб-калькулятор реальной выгоды и честного сравнения цен в супермаркетах (PWA).**

Современное, быстрое и полностью автономное веб-приложение, позволяющее моментально сравнить стоимость товаров за **1 кг**, **1 литр** или **1 штуку** прямо у магазинной полки с учётом любых акций, скидок и фасовок.

---

## ✨ Главные возможности

* ⚖️ **Поддержка любых единиц измерения:**
  * **Масса:** граммы (г), килограммы (кг) → пересчёт в **₽ / кг**.
  * **Объём:** миллилитры (мл), литры (л) → пересчёт в **₽ / л**.
  * **Штучные и счётные:** штуки (шт), рулоны (рул), капсулы (капс), таблетки (табл), пакетики (пак), порции (порц), метры (м).
* 🎯 **Умный расчёт акций и скидок:**
  * Обычная цена ценника.
  * Скидка в процентах (`-15%`, `-25%`).
  * Цена по карте лояльности магазина.
  * Акции «1+1 (второй бесплатно)», «2+1 (третий бесплатно)», «3+1».
  * Скидки «-50% на второй товар», «-70% на второй товар».
  * Мультипаки (наборы из нескольких упаковок).
* ⚡ **Live Preview (расчёт на лету):**
  * Результат и сравнение с лидером отображаются в реальном времени при вводе цифр ещё до добавления товара в список.
* 🏆 **Наглядная аналитика выгоды:**
  * Подсветка самого выгодного товара (бейдж «Самый выгодный»).
  * Точный расчёт разницы в % и в рублях (*«На 18.5% дороже лидера / переплата 24.50 ₽ за кг»*).
  * Итоговый баннер общей экономии по категории с праздничным салютом 🎉.
* 🗂️ **Вкладки и категории:**
  * Создание своих категорий (🥛 Молочка, 🧀 Сыр, 🥩 Мясо, 🧻 Для дома, ☕ Кофе и др.).
  * Автоматическое сохранение всех списков в `localStorage`.
* 📲 **PWA и 100% офлайн-режим:**
  * Мгновенный запуск без задержек.
  * Работает в цокольных этажах и магазинах без мобильной связи через Service Worker.
  * Установка на домашний экран смартфона (iOS / Android) в 1 клик.
* 💬 **Удобный шеринг и резервные копии:**
  * Генерация красивого форматированного отчета для отправки в Telegram / WhatsApp.
  * Копирование короткой ссылки со всеми товарами категории.
  * Полный экспорт и импорт базы в JSON.

## 🛠️ Стек технологий

* **Сборщик:** Vite 6
* **Фреймворк:** React 19 + TypeScript
* **Стили:** Tailwind CSS v4 + Lucide Icons
* **PWA:** `vite-plugin-pwa` + Workbox
* **Тестирование:** Vitest (100% покрытие математического движка)
